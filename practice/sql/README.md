# Google Play Store SQL Analysis

## Project Overview

This project uses a SQLite database created from a Google Play Store dataset.

The goal is to practice SQL and answer business-oriented questions using application data.

## Business Questions

The project analyzes questions such as:

1. How many applications are in the database?
2. Which categories contain the most applications?
3. What are the top 5 application categories?
4. What is the average rating for each category?
5. Which categories have more than 100 applications?
6. Which Racing applications have ratings above 4.5?
7. What are the highest- and lowest-rated applications?
8. What is the total number of installs for Racing applications?
